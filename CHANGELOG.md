# Changelog

All notable changes are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [3.0.0] - 2026-09-28

### Added

- Responsive Tailwind CSS interface with light and dark themes.
- Resizable desktop navigation and accessible mobile drawer.
- Device-local assessment history and real dashboard trends.
- Prediction confidence and probability distribution.
- Flask application package, API tests, Ruff, and Pytest configuration.
- CI, Dependabot, contribution templates, and Docker release automation.

### Changed

- Reorganized frontend and backend source trees by responsibility.
- Hardened API input validation, CORS configuration, and error responses.
- Split frontend routes into lazy-loaded production chunks.
- Updated React Router to a security-patched release.

### Removed

- Placeholder dashboard data and obsolete component-level CSS files.
- Unused landing page, navbar, footer, and Framer Motion dependency.
